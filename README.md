# MediaPieces
MediaPieces is a game designed to make interacting with your digital media collections more engaging.

## Gameplay
MediaPieces lets you select your own files or folders from your system and generate simple jigsaw puzzles to interact with. 

### File Selection
The File selection system within MediaPieces allows you to select an individual media file of a supported type or select one or more folders to pull files from.
If you select folders, all files within the folder and all its subfolders will be scanned, and the valid media files will be selected. 
When more than one media file is selected, a random file will be chosen to create the puzzles, one at a time, from each piece of media.

### Puzzle Difficulty
MediaPieces features a difficulty system that sets the number of puzzle pieces generated based on the difficulty that you select.
Each difficulty will generate puzzle pieces within its set's piece-count range, making them as square as possible given the aspect ratio of the selected media.

### Puzzle Interaction
Upon generation of a puzzle, you will be able to click and drag the puzzle pieces onto the board, and they will snap into any available board space. 
Put all the pieces into the correct positions, and you will complete the puzzle.

### Camera Movement
MediaPieces features camera movement that lets you pan and zoom.
To pan the camera, use the WASD keys or right-click and move the mouse.
To zoom the camera, use the scroll wheel.

### Puzzle Help
MediaPieces features a hint system that highlights one piece and its correct position on the board until it is placed or another hint is requested.

### Puzzle Skip
If you do not want to complete a specific puzzle and wish to move on to the next, MediaPieces features skip functionality that allows any puzzle to be skipped at any time.

### File Path Display
If you wish to better sort your media files using MediaPieces, it gives you some resources to help you locate specific files as you interact with puzzles made from them.
At any point when a puzzle is generated and can be interacted with, you are able to open up the menu, which discloses the exact file path of the file that the puzzle was generated from.

## How To Play
To download the current playable versions of MediaPieces, check the Releases tab for the current release
In these releases, download the ZIP file, extract it into an empty folder, and run MediaPieces.exe to play the game.

## Further Details

### Supported File Types
MediaPieces supports some of the most common digital media file types. Currently, these include:
- Images
  - PNG
  - JPG
  - JPEG
- Animated Images
  - GIF
- Videos
  - MP4
 
Support for additional media types may be added in future updates.

### Supported Operating Systems
Media pieces is currently supported only on Windows devices due to the integration of its file selection system into Windows File Explorer.
Support for other operating systems may be added in future updates.
