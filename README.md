# MediaPieces Development
This is the repository holding the files involved in the development of Media Pieces.

The project is being developed in the Unity game engine as a standalone game. 
The game is being developed for Windows devices and currently does not support any other operating systems.
In the future, support for other operating systems, such as Linux, may be added.

To download the current playable prototypes of MediaPieces, check the Releases tab for current releases and Pre-Releases
